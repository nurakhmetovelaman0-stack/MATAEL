# MATAEL 2.1 — Premium Glass foundation

Это обновлённый пакет существующего Android-проекта MATAEL, подготовленный на основе файлов репозитория GitHub.

## Что обновлено в этой сборке
- Таймер автоблокировки теперь работает при бездействии на открытом экране.
- Отдельно учитывается время в фоне, когда блокировка при сворачивании отключена.
- Настройка «Системная тема» учитывает светлый/тёмный режим Android.
- Стартовый экран Notes/Moments читается из настроек при запуске.
- PIN-диалог защищён от повторного открытия при переходах жизненного цикла.
- Напоминание о резервной копии появляется, если копии ещё не было или ей больше 30 дней.
- Сохранены существующие имена ключа Android Keystore, зашифрованного хранилища и формат MATAEL_BACKUP_V2.
- Добавлен минималистичный векторный значок MATAEL и версия проекта 2.1.

## Важно
Это не означает, что все идеи Moments и расширенного редактора уже реализованы. Полный перечень требований и статус реализации находятся в `docs/MATAEL_REQUIREMENTS.md`. Перед установкой на устройство сначала соберите APK и проверьте восстановление резервной копии на тестовых данных. Старые данные не удаляйте.

## Сборка
Откройте проект в Android Studio или запустите GitHub Actions workflow `MATAEL Build and Word Document`.

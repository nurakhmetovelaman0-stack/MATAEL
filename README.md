MATAEL 2.1 — Premium Minimal / Forest-Sage

Это объединённый проект существующего приложения MATAEL. Архив сохраняет структуру Android-проекта, включает обновлённый "MainActivity.java", документацию, workflow GitHub Actions и векторную иконку Forest/Sage.

Что включено в этот пакет

- Локальные заметки и Moments: создание, редактирование, удаление, поиск, избранное и закрепление.
- Локальное шифрование AES-GCM через Android Keystore с сохранением имён "matael_notes_aes_key" и "matael_vault_v2".
- PIN 4–8 цифр с PBKDF2-HMAC-SHA256.
- Резервная копия "MATAEL_BACKUP_V2" с PBKDF2 и AES-GCM.
- Автоблокировка при бездействии, настройка блокировки в фоне и выбор стартового экрана.
- Светлая/тёмная/системная темы; по умолчанию светлая Linen/Forest/Sage.
- Увеличивающаяся задержка после неправильного PIN.
- Защита от сохранения поверх хранилища при ошибке расшифровки.
- Повторная проверка PIN при открытии закрытой записи.
- Напоминание о резервной копии, если её нет или она старше 30 дней.
- Векторная иконка MATAEL в палитре Forest/Sage.

Что ещё не следует считать реализованным

Расширенный форматированный редактор, вложенные папки, фото из галереи и их включение в копию, календарь Moments, «В этот день», капсулы времени, полноценная система Goals, расширенная обратная связь с вложениями, предпросмотр выборочного восстановления, виджет и полная настройка Premium Glass требуют дальнейшей реализации и проверки. Их перечень сохранён в "docs/MATAEL_REQUIREMENTS.md".

Сборка и проверка

Открой проект в Android Studio или запусти workflow ".github/workflows/matael-android.yml" в GitHub Actions. Сборка APK и ручная проверка на Samsung Galaxy A34 в этой среде не подтверждены. Перед обновлением установленного приложения создай резервную копию и проверь её восстановление на тестовых данных. Не удаляй старую установку и её данные, пока не проверена совместимость.
